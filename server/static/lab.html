Discovery Lab

Hypotheses, real experiments, and a fair fight

Ask a question you'd like investigated. The lab states testable hypotheses, writes and runs Python in a sealed sandbox, then tries hard to break its own results. Every label comes from code that actually ran.

ProvenExperimental evidenceHypothesisDisproven

Proven: an exact symbolic identity, or every case checked. Experimental evidence: holds on the cases tested, not proven for all. Hypothesis: untested or the evidence conflicts. Disproven: code found a counterexample.
